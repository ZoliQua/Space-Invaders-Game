# Security Policy

## Supported versions

Only the latest release on the `main` branch of Space Invaders receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.
Email **zoltan.dul@gmail.com** with a description, steps to reproduce and the affected
version or commit. You will get an answer within 7 days.

The game runs entirely in the browser and stores data only in `localStorage` (stats, settings, autosaved session). It has no server component.
